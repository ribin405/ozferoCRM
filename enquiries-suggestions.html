Recommended combination

  • Status: A, compact tiles with color dots. Same 3 by 2 grid you already have at about half the height, with a status color on each, and the duplicate Add button removed on phones.
  • Filters: A, a Filters button with a bottom sheet. Search stays on top. Everything else moves into one sheet, and active filters show as removable tags so you can see and clear them without opening anything.
  • The Status dropdown leaves the filter panel on phones, because the tiles already do that job. Desktop keeps its current layout.
